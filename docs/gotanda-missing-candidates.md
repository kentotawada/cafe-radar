# 五反田・大崎で、地図には出ているのにカフェレーダーに無い店

2026-08-15 時点。OpenStreetMap を照合して抽出した**調査候補**。
地図のスタイルを streets-v2 に変えて店名が出るようになったことで、
「地図にあるのにピンが無い」店が見えるようになったのがきっかけ。

## そのまま取り込まないこと

- OSMにも閉店が残る。実例: Tea House Mayoor は 2026-08-14 に現地で閉店を確認して削除済みだが、OSMにはまだある
- 電源・Wi-Fi・座席数は入っていない。カフェレーダーの価値はそこなので、結局は調べる必要がある
- OSMは ODbL。取り込むなら継承条件の検討が要る

**候補として使い、実際に載せるのは自分で確認してから。**
