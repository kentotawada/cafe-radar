# Googleマップ版に残っている差分

`/`(Leaflet版・`src/components/CafeMap.tsx`)にあって `/map-google` に無いもの。
`/` を差し替える前にどれを埋めるか決めるための一覧。

調べ方: 両ファイルを機能名で突き合わせ、あるかどうかを実際に確認した(推測ではない)。
最終確認 2026-08-16。

## 移し終わったもの

- ピンとクラスタリング(先端の位置合わせ含む)
- 店舗ポップアップ(混雑の4段階報告、Wi-Fi速度、WEB会議、電源が使えなかった)
- 絞り込み全項目、駅で探す、お気に入り
- 縦リスト、横カード列
- お店を追加、「この店は無い/違う」報告
- ピンの説明、英語対応
- 現在地ボタン、開いた時点での現在地寄せ、拡大縮小ボタン
- お問い合わせ・プライバシーポリシー・法人向けの導線
- 出典表示(国土地理院 / Yahoo!)
- 承認済みの電源報告(outlet_verifications)
- 広告枠(ポップアップ内、`slot="cafe-popup"`)
- 情報が違うという報告(info_corrections)
- 席数 / 電源席数 / 電源席の場所メモの報告

## 差し替え後でもよいもの

### 1. 並び替え(おすすめ / 近い / 席数 / 空き / 静か)

`/map-google` のリストは地図中心からの距離順のみ。

### 2. 近くの空席候補(quickPick)

### 3. 過去の傾向からの予測

ライブの報告が無い店に、同じ曜日・時間帯の傾向を出す。

### 4. 地図の位置とUI状態の保存(localStorage)

開き直したとき前回の場所に戻る。

### 5. お店の共有(navigator.share)

### 6. デスクトップ向けレイアウト

`/map-google` はスマホ前提の1カラム。Leaflet版は横並びのリストを持つ。

### 7. 投稿レベルのバッジ(MyReporterBadge)

Leaflet版では `/` のヘッダー側にある(CafeMap.tsx ではない)。

## 差し替えの判断材料としてまだ測っていないもの

- **LCP**。Google Maps の JS は約200KB、Leaflet は約40KB。
  `/` の LCP を 5.1s から下げたばかりなので、測らずに入れ替えない。
  プレビューURLは Vercel のログイン保護が掛かっていて PageSpeed Insights から
  叩けないため、本番ドメインの別パスに置くか、保護を一時的に外す必要がある。
